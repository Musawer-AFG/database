# اصلاح منوی کناری با React Router

## چه چیز تغییر کرد؟

- برای تمام صفحه‌های برنامه مسیر (URL) جدا اضافه شده است؛ مثلاً `/sales`، `/purchases`، `/employees`، `/customers` و `/settings`.
- رنگ انتخاب‌شده فقط برای **صفحهٔ فعلی** نمایش داده می‌شود. بازکردن یک دستهٔ منو باعث رنگی ماندن دسته‌های پیشین نمی‌شود.
- وقتی دستهٔ جدید را باز می‌کنید، دستهٔ قبلی بسته می‌شود.
- دکمه‌های Back و Forward مرورگر بین صفحه‌های بازشده کار می‌کنند.
- صفحه‌های فروش، خرید، حسابداری، گدام، حاضری، نقش‌ها، صندوق نقدی و بخش‌های دیگر حفظ شده‌اند.
- ورود به سامانه و صلاحیت‌ها همان محدودیت‌های قبلی را دارند و یک لینک مستقیم دسترسی غیرمجاز نمی‌دهد.
- فایل `vercel.json` برای بازکردن لینک‌های مستقیم و Refresh در Vercel اضافه شده است.

## نصب روی ویندوز

در پوشهٔ پروژه، جایی که `package.json` است:

```powershell
npm install
npm run dev
```

بستهٔ `react-router` به وابستگی‌ها اضافه شده است. به دلیل در دسترس نبودن npm Registry در محیط تهیهٔ فایل، `package-lock.json` قدیمی حذف شده است؛ با `npm install` روی کمپیوتر خود lockfile تازه ساخته می‌شود. **فولدر node_modules را در GitHub آپلود نکنید.**

برای Vercel، تغییرات پروژه را Push کنید؛ فایل `vercel.json` مسیرهای React Router را به `index.html` بازنویسی می‌کند.

## آزمایش

۱. بل‌های فروش را باز کنید، آدرس باید `/sales` باشد. فقط همان مورد رنگی باشد.
۲. روی «محصولات» بروید، آدرس `/warehouse/products` شود. رنگ «بل‌های فروش» باید پاک شود.
۳. Back را بزنید؛ باید به بل‌های فروش برگردید.
۴. صفحه را روی `/warehouse/products` Refresh کنید؛ صفحهٔ محصولات باید باز شود.
۵. با یک کارمند محدود وارد شوید و یک مسیر غیرمجاز را مستقیم باز کنید؛ نباید محتوای ممنوع نمایش داده شود.

> برنامه هنوز یک نمایشی React با ذخیره‌سازی محلی مرورگر است؛ React Router امنیت حساب‌ها را در سمت سرور برقرار نمی‌کند.
