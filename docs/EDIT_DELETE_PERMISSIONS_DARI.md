# صلاحیت ویرایش و حذف معلومات

نسخه فعلی React یک **نمونهٔ نمایشی** است؛ دسترسی‌ها فعلاً در مرورگر کنترول می‌شوند و **امنیت سرور** ندارند.

## روش استفاده

۱. با حساب مدیر سیستم وارد شوید.
۲. مدیریت ← نقش‌ها و صلاحیت‌ها ← کاربران را باز کنید.
۳. کارمند موردنظر را ویرایش کنید.
۴. در «اجازه‌های اختصاصی برای همین کارمند»، مثلاً «ویرایش بل فروش» یا «حذف بل خرید» را فعال نمایید.
۵. حساب کارمند را ذخیره کنید. برای لغو صلاحیت، تیک آن را بردارید و دوباره ذخیره کنید.
۶. در «نقش‌ها» نیز می‌توانید این صلاحیت‌ها را به یک نقش اختصاص دهید؛ در آن صورت همهٔ کارمندان آن نقش اجازه می‌یابند.

## اصول

- ایجاد بل و ثبت پرداخت با ویرایش بل ثبت‌شده و حذف آن فرق دارد.
- کارمند با نقش پیش‌فرض فروشنده می‌تواند بل جدید بسازد ولی بدون اجازهٔ جداگانه نمی‌تواند بل ثبت‌شده را ویرایش یا حذف کند.
- گزینه‌های ویرایش و حذفِ موارد ثبت‌شده برای کارمند فاقد صلاحیت نمایش داده نمی‌شوند؛ در تابع ثبت نیز اجازه بررسی می‌شود.
- بل دارای پرداخت بعدی و بل خرید متصل به محموله برای جلوگیری از بی‌نظمی حسابات مستقیماً ویرایش نمی‌شوند. مبلغ ثبت‌شدهٔ پرداختی در ویرایش قابل تغییر نیست.
- حذف بل در صورتی که موجودی را منفی کند یا بل خرید به محموله مرتبط باشد ممنوع است.
- تغییر و حذف معلومات مشتریان، عرضه‌کنندگان، کارمندان، اجناس، گدام، اسناد حسابداری و معاشات صلاحیت جداگانه دارد.
- برای حذف بل یا ریکارد از کاربر تأیید خواسته می‌شود.

## قبل از استفاده حقیقی

در Node.js/Express باید هویت، نقش، اجازه‌های اختصاصی، ساعت شیفت و هویت کسب‌وکار از **دیتابیس** خوانده و هر درخواست تغییر/حذف تأیید شود. هر معامله باید در PostgreSQL با تراکنش و ثبت سوابق اجرا گردد و حذف اسناد مالی بهتر است با «باطل/اصلاح» و ثبت تاریخچه باشد، نه حذف بدون سابقه. ستون پیشنهادی برای اعطای مستقیم صلاحیت در migration شماره 011 اضافه شده؛ ارتباط با backend هنوز ساخته نشده است.
