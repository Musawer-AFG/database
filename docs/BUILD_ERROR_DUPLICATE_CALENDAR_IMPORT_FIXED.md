# رفع خطای تکرار import در App.jsx

اگر هنگام اجرای Vite پیام زیر را می‌دیدید، این نسخه مشکل را اصلاح می‌کند:

`Identifier 'afghanFromGregorian' has already been declared.`

در فایل `frontend/src/App.jsx` دو import جداگانه از `utils/afghanCalendar.js` وجود داشت و توابع `afghanFromGregorian` و `gregorianFromAfghan` دو بار وارد شده بودند. اکنون فقط یک import واحد وجود دارد که هر شش تابع ضروری را در بر می‌گیرد.

## اجرای برنامه در ویندوز

1. نسخهٔ قبلی را با فایل‌های ZIP جدید جایگزین کنید (در صورت داشتن معلومات ثبت‌شده، اول از آن‌ها نسخهٔ پشتیبان بگیرید).
2. PowerShell را در پوشهٔ اصلی پروژه باز کنید.
3. اگر قبلاً بسته‌ها را نصب نکرده‌اید، دستور `npm install` را اجرا کنید.
4. دستور `npm run dev` را اجرا کنید.
5. اگر سرور Vite از قبل باز است، با `Ctrl+C` ببندید و دوباره اجرا کنید.

بخش‌های بل شمارهٔ ۱ و قرارداد شمارهٔ ۴ با تنظیم رنگ دلخواه، متن قابل تغییر و بارگذاری لوگو در این نسخه حفظ شده‌اند.
